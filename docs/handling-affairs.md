## 1. 机制总图：八步闭环

```
        ┌────────────────────────── 循环，一次比一次正确 ──────────────────────────┐
        │                                                                          │
  ①立项定性质 → ②摸底调查 → ③判断抓主要 → ④定案留余地 → ⑤试点突破 → ⑥展开集中 → ⑦检查抓紧 → ⑧总结上升
        │                                                                          │
        └──────────────────────────── 新情况进来，重开一轮 ────────────────────────┘
```

每一步都有**入口条件、出口物、失败症状**。跳过任何一步，后面必返工。

---

## 2. 八步详解

### ① 立项：先划界限，再谈方案

**做什么**

- **定性质**：这是什么事？可逆还是不可逆？技术问题还是人的问题？内部矛盾还是外部冲突？
- **划界限**：哪些做、哪些**不做**；谁是"自己人"（可依靠的资源）、谁是"中间派"（可争取）、谁是"敌人"（要解决的问题）。
- **定验收**：成功的标准必须可验证（数字、现象、时间点）。

**毛选依据**

> "我们看问题一定不要忘记划清这两种界限：革命和反革命的界限，成绩和缺点的界限。记着这两条界限，事情就好办，否则就会把问题的性质弄混淆了。"（《党委会的工作方法》p841）

> "政策与策略是党的生命，各级领导同志务必充分注意，万万不可粗心大意。"（《关于情况的通报》p755）

**失败症状**

- 需求没划边界就开工 → 四面出击，越做越大，最后哪件都没做完；
- 把可逆决策当不可逆来纠结（过度准备），或把不可逆决策当可逆来赌（不留退路）；
- 验收标准是"做好一点""优化一下"——无法判定完成。

---

### ② 摸底：调查就是解决问题

**做什么**

调查不是"了解个大概"，而是**把结论从现场取回来**。技术（《反对本本主义》七条，p84–86）：

1. **开讨论式调查会**——不是一个人讲经验，要有辩论；
2. **选对人**——找真正明白情况的人（老手 + 有锐气的新人），与题无关的人不请；
3. **定纲目**——大纲 + 细目，事先准备，按纲发问；
4. **亲身出马**——不能只看书面报告，"二者是两回事"；
5. **深入一处**——彻底搞清一个地方或一个问题，往后就有门路；
6. **自己做记录**——假手于人不行；
7. **人数适度**——至少三人，否则囿于见闻。

**现代映射**

| 现场 | "调查会" | "纲目" | "一只麻雀" |
|---|---|---|---|
| 装插件失败 | 报错原文 + 日志 + 版本矩阵 | 错误码/网络/依赖/权限四类 | 最小可复现的一次安装 |
| 代码 bug | 复现步骤 + 相关调用链 | 输入/状态/时序/资源 | 最小可复现用例 |
| 写报告 | 用户原话 + 已有材料 + 反例 | 结论/证据/边界/读者 | 一个完整章节先写透 |

**出口物**：能用三句话说清——现状是什么、历史怎么来的、各方力量（资源/阻力）对比如何，并且带**数字**。

**失败症状**

- "我觉得应该是……"式判断（本本主义：只信文档/教程/上次经验）；
- 只看了最好的样本（只看成功案例，不看最差案例）；
- 调查完没有记录，下次重来。

> "你对于那个问题不能解决吗？那末，你就去调查那个问题的现状和它的历史吧！你完完全全调查明白了，你对那个问题就有解决的办法了。"（p81）

### ③ 判断：矛盾分析六问

**六问**（每次判断都过一遍）

1. **主要矛盾是什么？**（当前最卡住事情的那一个，不是最显眼的那个）
2. **矛盾的主要方面在哪？**（矛盾双方谁占主导，决定事情性质）
3. **几个问题里哪个是纲？**（纲举目张；抓住一个，其余自解）
4. **特殊性在哪？**（此时、此地、此人、此版本的差别；普遍规律不能直接套）
5. **数量界限在哪？**（阈值、百分比、临界点；没有数量就没有质量）
6. **能否转化？**（不利条件在什么条件下变成有利；对立面互相依存）

**两个方法**

- **两点论**：任何事都看到两面（成绩与缺点、有利与不利、快与慢）；
- **重点论**：两面之中必有一面是主要的，抓错主流"一定翻跟斗"（《工作方法六十条》p1203）。
- **十个指头**：九个指头是主流，一个指头是支流；既不能因一个指头否定全局，也不能因九个指头掩盖那一个。

**补充四则**（《矛盾论》《实践论》）

- **内外因分账**：外因是变化的条件，内因是变化的根据；归因先查内部结构，再谈环境（p187）。
- **计划可错**：默认计划会部分或全部不合实际，把"发现前所未料的情况→改计划"写进流程，而不是当例外（《实践论》p182）。
- **造条件促转化**：对立面能互相转化，但需要条件；工作着力点是创造那个条件，不是空喊"会好的"（p203）。
- **对抗分级**：先判是对抗性还是非对抗性矛盾，再选方式；能谈的先谈，别把非对抗的办成对抗（p204）。

**反面方法（要警惕）**

> "攻其一点或几点，尽量夸大，不及其余。"——这是脱离实际的形而上学方法（《工作方法六十条》p1203）。

**出口物**：一句话结论 + 数量依据 + **可反驳条件**（"如果 X 不成立，这个判断就翻"）。没有可反驳条件的结论，等于没判断。

### ④ 定案：三本账 + 留余地

**三本账**（《工作方法六十条》第九条 p1197）

| 账 | 用途 | 对外 |
|---|---|---|
| 必成账（保底） | 一定能做到的量 | **公布**，承诺只按这本说 |
| 期成账（争取） | 努力能达到的量 | 不公布，作为资源配置依据 |
| 理想账（野心） | 最好的情况 | 只做方向，不做承诺 |

**四条硬规矩**

1. **不打无准备之仗，不打无把握之仗**：准备 = 情报 + 资源 + 预案；有把握 = 关键不确定性已消除或已可控。
2. **慎重初战**：第一仗（第一个里程碑）必须选有把握的，只许成功——它决定士气和后续资源。
3. **留有余地**：指标留空间、时间留缓冲、话语留分寸。"不要图虚名而招实祸"（p1372）。
4. **战略上藐视，战术上重视**：目标上不怕（敢定），动作上抠细节（每个环节都当硬仗打）。

**补充四条**（《论持久战》）

- **分层固定**：战略级计划在阶段内稳住，执行级计划允许随时改；计划要按"环境不犯错"做保守假设，别把希望寄托在对手失误上（p302）。
- **预算枢纽段**：路线中间最苦的那一段单独配时间、资源、耐心——它最可能是转折点，也最容易被误判为失败（p279）。
- **留足本钱**：任何单点决策不得使主体失去继续参与的能力；宁可弃局部，保住下一手牌（p302–303）。
- **条件清单**：把"这次一定要成"改写成"要凑齐哪五条"，逐条挂人、逐条验收；成败"不决定于主观的愿望，而决定于具体的条件"（p276、p305）。

**失败症状**

- 承诺按理想账说 → 兑现不了，信任一次性透支；
- 无预案就上 → 一遇变化全线崩；
- 四面出击、平均用力 → 每个方向都不够，全部半途。

### ⑤ 试点：突破一点，取得经验

**做什么**

- **试验田**：选一个最小单元，把全流程完整走一遍；
- **解剖麻雀**：一个最坏的、一个中等的、一个最好的——三个样本就能看出分布，不必普查（p1370）；
- 试点要**真做**，不是沙盘推演；要记录坑、耗时、判据。

**毛选依据**

> "突破一点，取得经验，然后利用这种经验去指导其他单位……就无法考验自己提出的一般号召是否正确。"（《关于领导方法的若干问题》p527）

> "普及推广试验田。这是一个十分重要的领导方法……突破一点就可以推动全面。"（《工作方法六十条》p1198）

**出口物**：一份**可复制**的做法（步骤 + 坑 + 判据 + 耗时），而不是"我试过了，行"。

---

### ⑥ 展开：一个中心 + 集中力量 + 抓两头

**部署八条**

1. **一个中心**：同一时间只设一个中心工作，其余排第二、第三位。"不能同时有许多中心工作"（p529）。
2. **弹钢琴**：十个指头都要动，但要有节奏、互相配合——中心工作抓紧，其他方面也点到（p840）。
3. **集中力量**：把资源压到主攻方向，"伤其十指不如断其一指"；不搞平均主义。
4. **一般号召 + 个别指导**：任何部署都要落到"谁、在哪一步、做什么、什么算完成"。只发号召不落实，就是官僚主义（p527）。
5. **抓两头带中间**：抓最好的和最差的，中间自然跟上（p1199）。
6. **分工而又统一**：一件事只有一个负责人；"大权独揽，小权分散。党委决定，各方去办。办也有决，不离原则。工作检查，党委有责。"（p1202）
7. **争主动**：任何安排都要问一句"这让我更自由还是更被动"；被动不是靠一次大胜摆脱的，而是靠一堆局部主动攒出来的（《论持久战》p291–292）。
8. **安民告示**：开会/启动前先通知议题、材料、要解决的问题；"兵马已到，粮草未备"是坏事（p840）。

**失败症状**

- 同时开五个战场 → 每个都推不动；
- 只发通知不跟进 → 事情停在纸上；
- 平均分配资源 → 哪个方向都形不成突破。

---

### ⑦ 检查：抓而不紧，等于不抓

**节奏**（《工作方法六十条》p1197–1198）

- **全面规划，几次检查，年终评比**——三个方法配套；
- **一年至少检查四次**（季度一次）；重要任务在未上轨道前**每月一次**；
- **五年看三年，三年看头年，每年看前冬**——时机上有所侧重。

**检查什么**

| 维度 | 问题 |
|---|---|
| 数量 | 进度对不对？差多少？ |
| 质量 | 有没有越过质量/政策界限？ |
| 方向 | 还是不是原来那个中心？有没有偏？ |
| 人 | 谁卡住了？是能力、意愿还是资源？ |

**怎么说**

- 用**数字 + 对比**说清形势（《关于情况的通报》的写法：敌我兵力、旅数、人数、月歼敌数，一目了然）；
- 盯住"可执行的最小节奏"：如"平均每月消灭八个旅"——把大目标拆成每月可检查的量（p758）。

**毛选依据**

> "什么东西只有抓得很紧，毫不放松，才能抓住。抓而不紧，等于不抓。伸着巴掌，当然什么也抓不住。"（《党委会的工作方法》p840）

### ⑧ 总结：经验上升为理论，再回到实践

**复盘四问**

1. **哪一步判断错了？**（回到第③步的六问，找出错在哪个问）
2. **哪个做法可以复制？**（写成步骤，别人照着能做成）
3. **哪条规则要改？**（改流程/清单/记忆，而不是"下次注意"）
4. **下一步的新情况是什么？**（重开第②步）

**态度**

- **惩前毖后，治病救人**：对事不对人；目的是改，不是罚；
- **团结—批评—团结**：从团结的愿望出发，经过批评，达到新的团结；
- **批评与自我批评**：先说自己，再说别人；"知无不言，言无不尽；言者无罪，闻者足戒"（《论联合政府》p636）。

**升华**

> "一个正确的认识，往往需要经过由物质到精神，由精神到物质，即由实践到认识，由认识到实践这样多次的反复，才能够完成。"（《人的正确思想是从哪里来的》p1409）

把个案经验抽象成**规则**，写进 SOP / 文档 / 长期记忆——否则经验随人走，下次重犯。

### 贯穿：学习（把方法本身当工具磨）

- **有的放矢**：先定"的"（要解决的具体问题），再选"矢"（理论/工具）；没有"的"不放箭（《改造我们的学习》p473）。
- **三种脱节自查**：有没有研究现状？有没有研究历史？有没有真的用上？三条缺一条，就是理论与实际分离（p471）。
- **反对两头**：本本主义（只信文档/教程）与经验主义（只信旧法）都是主观主义，解药都是先调查。
- **学什么**：学点哲学、历史、文法与逻辑（《工作方法六十条》p1204）。
- **验收**：精通的目的全在于应用——能解决一两个具体问题才算学成（《整顿党的作风》p481）。

## 4. 六件拿来就用的工具

### 工具 1：调查纲目模板

```
议题：____________
大纲：1. 现状（数字/现象）  2. 历史（怎么变成这样）  3. 力量对比（资源/阻力）
细目：每个大纲下 3–5 条具体问题
对象：最坏 1 个 + 中等 1 个 + 最好 1 个样本
记录：谁记、记什么（原话 + 数据 + 反例）
```

### 工具 2：矛盾分析六问（判断卡）

```
1 主要矛盾：
2 主要方面：
3 哪个是纲：
4 特殊性：
5 数量界限：
6 转化条件：
结论一句话：
可反驳条件：若 ______ 不成立，则结论翻
```

### 工具 3：三本账

```
必成（公布）：______
期成（不公布）：______
理想（只做方向）：______
```

### 工具 4：复盘四问

```
哪步判断错了 → 哪条做法可复制 → 哪条规则要改 → 下轮新情况
```

### 工具 5：会议/文档精简规则

- 会前**安民告示**：议题、材料、要定的事；
- 会上**材料与观点统一**：用材料说明观点，不要只堆材料不给结论（p1203）；
- 文件**准确性、鲜明性、生动性**：概念明确、判断恰当、推理有逻辑（p1204）；
- **精兵简政**：能一页说清不写三页；会议不要开太长（p840）；
- 重要文件**自己动手写**，不全部委托（p1204）；
- **提—析—解**：任何有指导性的表达都走三步——提出问题 → 系统分析 → 综合给出性质与办法；只罗列不结论的材料退回（《反对党八股》p495）。

### 工具 6：传达的节奏

> "要下些毛毛雨，不要在几小时内下几百公厘的倾盆大雨。"（p1203）

大变更要分次释放、给缓冲；"强迫受训""强迫签字"要尽可能减少。

## 5. 映射到本工作（DSH / 工程 / 写作）

| 环节 | 装插件/修环境 | 改代码 | 写报告/方案 |
|---|---|---|---|
| ①立项 | 明确"能用"的验收标准 | 明确 bug 的可复现判据 | 明确读者与用途 |
| ②调查 | 报错原文、日志、版本、hosts/DNS、证书链 | 复现、调用链、可变状态 | 用户原话、已有材料、反例 |
| ③判断 | 主要矛盾是网络/依赖/权限哪一类 | 根因 vs 表象 | 核心结论是什么（一句话） |
| ④定案 | 备份、可回滚、留退路 | 最小改动方案 + 回滚点 | 主结论 + 保留意见 |
| ⑤试点 | 先用一个包验证 | 先在一处改，跑通再铺开 | 先写透一节 |
| ⑥展开 | 逐个安装、逐个验证 | 分批提交、小步快跑 | 结构先定、逐节填 |
| ⑦检查 | 每步都实测（不看"应该行"） | 每步跑测试 | 每节自检论据是否支撑结论 |
| ⑧总结 | 把踩坑写进记忆/文档 | 把根因写进注释/ADR | 把方法沉淀成模板 |

**AI 助手场景下的"群众"** = 用户真实需求、现场日志与数据、可复现的实验。脱离这三者的推理，就是本本主义。

## 8. 一句话总结

**先把情况搞清楚（调查），再把主要矛盾抓住（判断），然后用有余地的方案、集中力量、突破一点（定案+试点+展开），一路抓紧检查（检查），最后把经验变成规则再回到实践（总结）。**

这就是毛选里那套"从群众中来，到群众中去；从实践中来，到实践中去"的处理事务机制。
