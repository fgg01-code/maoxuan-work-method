# 毛选式处理事务机制 · DSH Skill

> 把《毛泽东选集》里的做事方法，压缩成一套可执行的**八步闭环**：立项定性质 → 调查 → 抓主要矛盾 → 定案留余地 → 试点 → 展开 → 检查 → 总结。

这是一个 [DeepSeek Harness](https://github.com/huzhengcai471-crypto)（dsh）技能：装进 `~/.agents/skills/` 后，遇到含糊需求、多目标取舍、长周期项目、故障排查、不可逆决策、方案评审或复盘时，会自动加载。

---

## 为什么值得装

大多数返工不是因为不努力，而是因为**跳步**：

- 没调查就下结论（拍脑袋）；
- 把最显眼的问题当主要矛盾（平均用力）；
- 方案没有回滚点（一遇变化全线崩）；
- 试点只有「我试过了」（经验无法复制）；
- 复盘只写「下次注意」（规则没改，错误重演）。

这套技能把每一步的**闸门**写死：不满足条件，不许进下一步。

---

## 八步闭环

| 步 | 动作 | 产出 | 闸门 |
|---|---|---|---|
| ① 立项 | 定性质、划界限（做/不做）、定可验证验收 | 一页任务卡 | 说不出「哪些不做」→ 停 |
| ② 调查 | 三样本（最坏/中等/最好）+ 原话、日志、数据 | 情况清单（带数字） | 说不出三句现状 → 停 |
| ③ 判断 | 六问：主要矛盾、主要方面、哪个是纲、特殊性、数量界限、转化条件 | 一句话结论 + **可反驳条件** | 写不出可反驳条件 → 停 |
| ④ 定案 | 三本账（必成/期成/理想）、留余地、最坏预案、回滚点 | 方案卡 | 没有回滚点 → 停 |
| ⑤ 试点 | 最小单元走完整流程 | 可复制做法 | 只有「我试过了」→ 停 |
| ⑥ 展开 | 一个中心、集中力量、抓两头带中间、一般号召 + 个别指导 | 分工表（唯一负责人） | 没有唯一负责人 → 停 |
| ⑦ 检查 | 查数量、质量、方向、人；固定节奏 | 检查记录 + 偏差修正 | 没有固定检查点 → 停 |
| ⑧ 总结 | 复盘四问，经验写成规则 | 规则改动 | 只写「下次注意」→ 停 |

⑧ 的产出回到 ②，进入下一轮，每轮必须有认知增量。

**六病自查**：本本主义（只信文档）、经验主义（只信旧法）、命令主义（硬推）、尾巴主义（盲从）、官僚主义（只发号召）、急性病（四面出击）。

## 安装

### 方式一：手动复制（任选其一）

```powershell
# Windows
New-Item -ItemType Directory -Force "$env:USERPROFILE\.agents\skills\maoxuan-work-method" | Out-Null
Copy-Item .\SKILL.md "$env:USERPROFILE\.agents\skills\maoxuan-work-method\SKILL.md"
```

```bash
# macOS / Linux
mkdir -p ~/.agents/skills/maoxuan-work-method
cp SKILL.md ~/.agents/skills/maoxuan-work-method/SKILL.md
```

### 方式二：整仓克隆

```bash
git clone https://github.com/huzhengcai471-crypto/maoxuan-work-method.git \
  ~/.agents/skills/maoxuan-work-method
```

装好后新开一次会话（或刷新技能目录），即可在技能列表里看到 `maoxuan-work-method`。

## 怎么用

- **自动触发**：任务描述里出现「需求含糊 / 多个问题纠缠 / 要不要 all-in / 排查根因 / 中期没进展 / 复盘」等信号时自动加载；
- **手动调用**：直接说「按八步走」「用毛选方法处理这件事」，或调用 `skill maoxuan-work-method`。

技能里自带五张表可直接复制：任务卡、调查纲目、六问判断卡、检查节奏、复盘四问。

## 边界

- 小任务可以合并步骤（如 ①②、③④），但**不许跳步**：没调查不下结论、没试点不铺开、没检查不算完成。
- 这套方法管的是「怎么把事做成」，不替代领域知识。
